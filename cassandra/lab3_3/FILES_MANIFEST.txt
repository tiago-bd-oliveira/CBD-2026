HOW TO GET STARTED
──────────────────────────────────────────────────────────────────────────
Option 1 - Fastest (5 minutes):
  $ cd lab3_3
  $ ./run.sh
Option 2 - Manual Build:
  $ mvn clean package
  $ java -jar target/lab3_3-1.0-SNAPSHOT.jar
Option 3 - With Maven Exec:
  $ mvn exec:java -Dexec.mainClass="cbd.Main"

The dataset that was used was a song lyric dataset. Each song is a document with a title, artist, genre tag, year, views, featured artists, and lyrics raw text. 

The original dataset was huge, so I only used 500 songs. Then I did some processing to enrich the collection for queries. I split the features string into an array and split the lyrics raw text into sections with line count and type.

This was the final structure of the documents
{
  _id: ObjectId,
  title: str,
  tag: str,
  artist: str,
  year: int,
  views: int,
  features: str[],
  lyrics: [
    {
      section_id: int,
      type: str,
      line_count: int,
      content: str
    }
  ],
  id: str,
  language_cld3: str,
  language_ft: str,
  language: str,

}
